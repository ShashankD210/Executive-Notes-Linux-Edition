# Implementation Roadmap

## Phase 0 — Foundation (this project package)
Baseline catalogue, standalone application, source artefacts, requirements, architecture documents, SQL schema and API scaffold.

## Phase 1 — Secure MVP
Implement SSO/OIDC, MFA policy, tenant model, RBAC/ABAC, PostgreSQL persistence, migrations, server-side validation, append-only audit events, evidence object storage and secure exports.

## Phase 2 — Governance workflows
Risk register, control assessments, audit engagements, findings, remediation workflows, risk acceptance, policy approvals and compliance obligations register.

## Phase 3 — Enterprise integrations
SCIM, ITSM/CMDB, SIEM, vulnerability management, cloud security posture, endpoint configuration, identity governance and document repository integrations.

## Phase 4 — Assurance automation
Evidence freshness, control test scheduling, hardening posture ingestion, continuous control monitoring, dashboards and executive reporting.

## Phase 5 — Production readiness
Penetration test, privacy assessment, disaster recovery test, load test, accessibility review, operational runbooks, support model, change control and go-live approval.

## Go-live gates
Named service owner; approved data classification; SSO/MFA; authorization test coverage; logging/SIEM; encryption/key management; backup/restore; incident response; vulnerability remediation; legal/privacy review; user acceptance; documented RTO/RPO and support rota.
